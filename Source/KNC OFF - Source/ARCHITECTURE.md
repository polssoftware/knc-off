# KNC OFF architecture

Audio parameters retain stable string IDs. Host integration snapshots atomic values once per block, then the Engine smooths effective sample values. Independent primitives/engines implement transient detection, compression, three saturation curves, triggered sub synthesis, spectral enhancement, clipping, pitch shifting, crushing, delay, reverb, chorus, EQ and width. Allocation and buffer clearing occur only during prepare.

The main and auxiliary row permutations are packed into separate atomic words with four bits per module identity. Unique in-range identities are validated before state restore. UI reordering moves the image-backed components while retaining parameter identity. DSP changes order behind a short dry crossfade.

The audio thread now publishes stereo per-sample min/max values into a preallocated 524288-slot heap ring. Slots contain atomic extrema and a monotonically stamped sequence; the GUI checks the stamp before and after reading and skips overwritten/in-progress slots. An atomic write position publishes completed blocks. The 128-column GUI aggregates exact min/max over the selected time interval at fixed amplitude scaling, retaining polarity and stereo extrema without cancellation. At up to 60 Hz it repaints only after new sample publication or a view-window change. Click the waveform for 100/250/500/1000/2000 ms, default 500 ms. No waveform normalization, smoothing, random motion or audio-thread allocation/locks. Old 10 ms peak/RMS and FFT helpers remain available for regression tests but do not drive the visible waveform. The GUI rotates cropped original knob sprites; it does not synthesize knob drawing graphics. All original selectors and brackets travel with their effect tiles. Settings panels share a PaperLook and a common creation function, making them independently verifiable. Their final Mix slider binds to the same effect parameter as the main knob. The delay time field alternates between a beat-fraction slider and a millisecond slider in the same bounds. Movable knobs retain drag routing without a hold-highlight box. A separate image-backed title component provides a <=3.5% audio-reactive opacity pulse.

Schema 7 stores all parameter values, selected factory preset, mainOrder and auxOrder. Old states migrate new delay parameters to ms mode, preserving old manual timing. Old fractional pitch targets round to whole semitones. Schema-1/2 negative attack and out-of-range gains clamp to the current ranges, and the old centred width mapping migrates to 0-based enhancement. Invalid or incomplete new states are rejected.

## Original unified twelve-module roadmap

Reserved identities: Transient, Compressor, Saturation, Sub, EQ, Spectral, Stereo, Space, Shift, Texture, Loudness, Clipper. Current algorithms cover many categories but do not claim every algorithm in the original specification. Dedicated texture/loudness engines, formant processing, more advanced module modes, repeated instances, oversampling, locks and undo remain future work.

Future banks should calculate effective values from manual base values plus active-bank modulation, retain separate values for inactive banks, and avoid overwriting manual settings or enabling unused modules. Bank names currently identify factory starting presets; they are not full macro-bank implementations.
